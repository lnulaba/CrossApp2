# Лабораторна робота 1

## Тема

Налаштування середовища і старт проєкту.

## Мета

Створити solution та консольний .NET-застосунок, перевірити його запуск і
зафіксувати предметну область для подальшого розвитку проєкту.

## Середовище

- ОС: macOS;
- архітектура: визначається через `RuntimeInformation.ProcessArchitecture`;
- SDK: .NET 8 SDK;
- редактор: Visual Studio Code;
- TFM: `net8.0`;
- RID для self-contained публікації: `osx-arm64`;
- група: ФЕІ-34.

## Обрана предметна область

Обрано предметну область **Бібліотека**. Сутності: `Book`, `BookCopy`,
`Reader`, `Loan`. Застосунок призначений для обліку видач примірників книг
читачам і їх повернення.

## Результат

Програма виводить інформацію про операційну систему, архітектуру процесу,
версію CLR, runtime та робочі каталоги. Параметр `--json` виводить ці дані
одним JSON-рядком.

Self-contained публікація перевірена для `osx-arm64` і `linux-x64`.

## Висновок

Створено базовий solution `CrossApp` із консольним проєктом `Cli`. Каркас
готовий до розширення в наступних лабораторних роботах.
